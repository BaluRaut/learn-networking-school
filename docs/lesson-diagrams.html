1 📮 Networking का

शाळेचे टपाल — पत्राला पत्ता, खोली क्रमांक आणि प्रवासाचा रस्ता असेल तरच दोन संगणक बोलू शकतात.

2 🏫 IP पत्ते & subnets

इमारतीचा पत्ता — IPv4, IPv6, CIDR विभाग, खाजगी पल्ले, आणि गेटवरचा एकच सार्वजनिक पत्ता (NAT).

संपूर्ण धडा 02 वाचा →

3 🚪 Ports & sockets

खोली क्रमांक — port कोणता प्रोग्राम ते सांगतो; socket म्हणजे एका खोलीतले एक बाक; सुप्रसिद्ध खोल्या 0–1023.

संपूर्ण धडा 03 वाचा →

4 📦 थर (layers)

पोहोच-साखळी — पत्र, लखोटा, पिशवी, व्हॅन, रस्ता: Ethernet वर IP वर TCP वर HTTP, आणि प्रत्येक थर फक्त शेजाऱ्याला का ओळखतो.

संपूर्ण धडा 04 वाचा →

5 📬 TCP विरुद्ध UDP

नोंदणीकृत टपाल विरुद्ध लाउडस्पीकर — TCP चा handshake, पावत्या आणि क्रम; UDP चे स्वस्त, हरवणारे आवाज.

संपूर्ण धडा 05 वाचा →

6 📖 DNS

शाळेची निर्देशिका — नावाचा पत्ता होतो; resolvers, records, TTL, आणि 'DNS आहे का?' ने प्रत्येक outage का सुरू होते.

संपूर्ण धडा 06 वाचा →

7 📨 तारेवरचे HTTP

लखोट्यातली चिठ्ठी — request line, headers, body; keep-alive; HTTP/1.1, /2 आणि /3 (QUIC).

संपूर्ण धडा 07 वाचा →

8 🔒 TLS & certificates

सील केलेला लखोटा — certificates, सही करणारी CA, handshake, SNI; HTTPS आणि प्रत्येक 'S' का.

संपूर्ण धडा 08 वाचा →

9 🧭 Routing & internet

कॉरिडॉरचा नकाशा — default gateway, prefix नुसार पुढे पाठवणारे routers, traceroute चे hops, MTU, आणि एका परिच्छेदात BGP.

संपूर्ण धडा 09 वाचा →

10 🚧 Firewalls, NAT & VPN

गेट — परवानगी-याद्या, stateful नियम, security groups, NAT, SSH बोगदे आणि VPN: कोणत्या खोलीत कोण जाऊ शकते.

संपूर्ण धडा 10 वाचा →

11 🏪 Load balancers, proxies & CDN

स्वागत कक्ष — L4 विरुद्ध L7, reverse proxies, health checks, sticky sessions, आणि वाचकाजवळची प्रत (CDN).

संपूर्ण धडा 11 वाचा →

12 🔧 Network चे debugging

तपासणीची शिडी — DNS → पोहोच → route → port → TLS → HTTP → logs; latency विरुद्ध bandwidth; साधनपेटी.
